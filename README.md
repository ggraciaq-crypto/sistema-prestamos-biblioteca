## Descripción del proyecto

Este repositorio contiene la documentación y las evidencias correspondientes a la Práctica Experimental 2, relacionada con la organización del equipo, la planificación de actividades y el diseño inicial de un sistema de gestión de préstamos de libros de una biblioteca.
